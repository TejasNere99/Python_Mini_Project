# ✈️ Travel Itinerary Planner — Python Project  

> 🚀 A smart, interactive travel planner that helps you calculate trip costs, plan destinations, food, hotels, and more — all through a simple command-line interface!

---

## 🧭 Overview

**Travel Itinerary Planner** is a Python-based project that lets users plan complete trips with:
- Real-time **distance calculation** between cities using Geopy 🌍  
- Smart **date validation and duration calculation** 📅  
- Dynamic **hotel, food, and travel cost estimation** 💸  
- Personalized **activity recommendations** based on trip length 🧳  
- Curated **city-based attractions, food, and entertainment suggestions** 🍲🎬🛍️  

---

## 🧠 Key Features

| Category | Description |
|-----------|-------------|
| 🌍 **Distance Calculator** | Uses **Geopy API** to fetch coordinates and calculate accurate travel distance. |
| 📅 **Date Validator** | Validates user-entered dates and calculates the number of travel days. |
| 🏨 **Hotel Selection** | Choose between **Budget, Standard, or Luxury** hotels with nightly cost estimation. |
| 🍽️ **Food Planner** | Select daily meals from curated menus with automatic pricing. |
| 🎬 **Entertainment Hub** | Explore theaters, movies, and local attractions in your destination city. |
| 🚗 **Transport Estimator** | Choose between **Airline, Train, Bus, or Car** with cost per km calculation. |
| 💡 **Smart Suggestions** | Gives personalized travel tips based on your trip duration. |

---

## ⚙️ Tech Stack

- **Language:** Python 🐍  
- **Libraries Used:**
  - `geopy` → For geolocation and distance calculation  
  - `datetime` → For date validation and difference calculation  

---

## 🧩 How It Works

1. **Input Locations** — Enter two cities (e.g., Pune → Mumbai)  
2. **Trip Dates** — Provide start and end dates in `YYYY-MM-DD` format  
3. **Transport Mode** — Choose from airline, train, bus, or car  
4. **Hotel Type & Nights** — Select your hotel and number of nights  
5. **Food Choices** — Pick meals for each day  
6. **City Attractions** — Choose what to visit, eat, and shop in your destination city  
7. **Get Full Itinerary + Cost Summary!**
